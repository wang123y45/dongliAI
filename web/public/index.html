下载冻梨AI电脑版

Windows 安装包、macOS 应用包和 Linux / Ubuntu 启动方式。登录同一账号，对话记录与网页端同步。

WIN

Windows 10 / 11

x64 安装包，双击安装，自动创建桌面快捷方式。

下载 Windows 安装包
约 116 MB · 未签名 · 首次运行如提示 SmartScreen，选“更多信息 → 仍要运行”。
MAC

macOS

ZIP 应用包，解压后把“冻梨AI”拖进 Applications。

下载 macOS 应用包
约 235 MB · 未签名 · 首次打开请右键 → 打开；Apple Silicon 需安装 Rosetta 后运行。
LNX

Linux / Ubuntu

提供源码启动方式，适用于 Ubuntu 20.04 及以上桌面环境。

下载 Linux 源码包
sudo apt install -y nodejs npm unzip dongli-desktop-src-1.0.0.zip cd dongli-desktop npm install npm start
需要 Node.js 18+。首次启动会下载 Electron 运行时。
iOS

iPhone / iPad

Xcode 15+ 工程源码，包含麦克风、相机和附件上传适配；需使用自己的 Apple 开发者账号签名后真机安装。

下载 iOS 工程
源码仓库包含桌面端、Android 与 iOS Xcode 工程；iOS 用 Xcode 15+ 打开 dongli-ios/DongliAI.xcodeproj。 查看 GitHub
